# 启动记账APP

用户想要运行「弥厶釉记账」项目，按以下步骤操作：

## 步骤

1. **检查依赖**：如果项目里没有 `node_modules` 文件夹，先执行 `npm install` 安装依赖（如果已存在就跳过这步）。

2. **启动开发服务器**：用后台运行方式（run_in_background）执行 `npm run dev`，因为服务器会一直运行不退出。

3. **等待启动完成**：查看后台任务输出，等出现类似 `Local: http://localhost:5173/` 的提示（一般几秒钟），说明启动成功。

4. **打开浏览器**：执行 `explorer.exe "http://localhost:5173/"`，在用户的默认浏览器里打开应用。

5. **告知用户**：用大白话告诉用户"程序已经启动，浏览器已打开"，并说明想停止时直接说一声即可。

## 注意事项

- 开发服务器默认端口是 5173。如果后台输出提示端口被占用，以 Vite 实际使用的端口号为准，用实际端口打开浏览器。
- 服务器必须保持后台运行，不要用会一直卡住等待的方式启动。
- 如果启动报错，把错误信息翻译成大白话解释给用户，并想办法解决。
